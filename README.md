# Dashboard Financeiro - Controle Interno 2026

Este repositório contém o painel interativo de análise financeira e consolidação de resultados (Maio a Agosto de 2026).

## 📊 Indicadores Acompanhados
- **Receita Total (Faturamento)**
- **Gastos Fixos por Sede**
- **Gastos Variáveis Operacionais**
- **Retiradas / Despesas dos Sócios**
- **Lucro Líquido Consolidado**

## 🚀 Como Visualizar
Acesse o link do GitHub Pages publicado nas configurações do repositório ou abra o arquivo `index.html` diretamente em qualquer navegador web.

## 🛠️ Tecnologias
- HTML5 / Tailwind CSS
- Chart.js (Gráficos interativos)
- FontAwesome Icons
